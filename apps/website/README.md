# website

The Astro app behind [umangkumarr.github.io](https://umangkumarr.github.io).

```bash
bun run dev      # http://localhost:3010
bun test
bun run build    # static output in dist/
```

Content lives in `src/lib` (timeline, writing, stack, identity) and
`src/pages/about.astro`. See the repo root README for the full editing map.
